家里宽带升级后换成了电信千兆光猫——烽火 HG2543C1。如果需要改桥接模式使用自己的路由器拨号，通常需要获取超级管理员（telecomadmin）权限。记录一下通过 Telnet 获取超管密码的步骤。

<!--more-->

# 准备工作

1. 确保电脑已通过网线连接到光猫的 LAN 口，或者已连上光猫自带的默认 WiFi。
2. Windows 系统默认未启用 Telnet 客户端功能，需要先开启：
   - 打开「控制面板」→「程序和功能」→「启用或关闭 Windows 功能」→ 勾选「Telnet 客户端」并确定。
   - 或者以管理员身份打开 PowerShell 执行以下命令：
   ```powershell
   # 启用 Windows Telnet 客户端功能
   dism /online /Enable-Feature /FeatureName:TelnetClient
   ```

# 烽火HG2543C1 获取超管密码

1. **开启光猫 Telnet 服务**：  
   打开浏览器，在地址栏输入以下网址并回车：
   <http://192.168.1.1:8080/cgi-bin/telnetenable.cgi?telnetenable=1>  
   访问后页面如果提示成功，即表示光猫的 Telnet 端口已经开启。

2. **连接光猫 Telnet**：  
   打开命令提示符（CMD）或 PowerShell，输入：
   ```bash
   telnet 192.168.1.1
   ```

3. **登录 Telnet**：  
   连接成功后会提示输入用户名和密码：
   - **Login（账号）**：`root`
   - **Password（密码）**：光猫背面铭牌贴纸上印着的**默认 WiFi 密码**（也是初始终端配置密码）
   *(注：在终端中输入密码时屏幕不会显示字符，直接输完敲回车即可登录)*

4. **查看超级管理员账号与密码**：  
   登录成功后，在终端中输入以下命令查看光猫的出厂配置文件：
   ```bash
   cat /flash/cfg/agentconf/factory.conf
   ```
   查看输出内容（通常在第二行），即可直接看到明文的超级管理员账号与密码：
   - 账号通常为 `telecomadmin`
   - 后面对应的字符串即为超级管理员密码。

# 登录超管后台

1. 获取到超管密码后，在浏览器访问后台地址：<http://192.168.1.1:8080>。
2. 使用账号 `telecomadmin` 及查到的密码登录，即可进入超级管理员后台进行改桥接、关闭 DHCP 或关闭 TR069 等操作。
